# Response template

Written by the answering seat into the requester's `to-<seat>/` folder.

```
request id:     REQ-YYYYMMDD-<from-seat>-<n>
answered by:    <seat>
date:           YYYY-MM-DD HH:MM ET
answer:         <the answer, in one paragraph or fewer>
artifact:       <file path, document id, commit sha, or fetched URL>
verification:   verified | relayed
```

## Rules

**An answer without an artifact is recorded as relayed, never as verified.** A figure carried from
memory is a relay, and it is marked as one. The standing precedent applies: no artifact, no
verification.

**If the answer is "nothing has changed", say exactly that.** It is a complete answer and it is the
most common one.

**The responding seat does not clear anything.** It answers a question. Clearance stays where the
standing rules put it.
